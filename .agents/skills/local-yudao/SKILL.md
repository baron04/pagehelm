# 芋道本地验收

正式入口是源码目录的`./local`，不依赖分支或worktree类型。使用该脚本所在目录的代码，不从内部测评运行器启动服务。

- 默认环境1：`./local`，地址`http://localhost:40001`。
- 显式环境2：`./local --env 2`，地址`http://localhost:40002`。
- 诊断用`status`、`check`；日志用`logs`，基础服务用`logs app`。
- 模型`.env`改动后用`restart`，结束使用用`stop`；只停止所选助手，保留业务服务和数据。

未指定时始终用环境1。用户已为当前任务指定环境2后，每条启动、诊断、日志、重启和停止命令都带`--env 2`，例如`./local --env 2 status`；不因报错或占用自动换环境。

首次准备或排错读[本地指南](../../../docs/guides/local-yudao.md)。助手纳入各自Compose项目，普通代码更新只重启助手，前端变化才构建，依赖变化才重建镜像。源码目录被其他任务使用时，不接管其运行中的环境；先从原目录停止对应助手。

基础缓存仍为`.q0-cache/yudao`。新实例状态在`$XDG_STATE_HOME/web-operation-agent/yudao/env1/`或`env2/`，未设置时根目录为`~/.local/state`。保留所选实例的数据库配置，已有卷而配置丢失时恢复原配置，不重置密码。旧`woa-yudao-local-deprecated`项目、数据卷及`48163`宿主机助手单独保留，新入口不管理它们，`local.local.toml`仅供旧启动器使用。

日常启动不恢复数据库、重置账号、seed或运行测评。凭据只读取必要配置，不输出`.env`、数据库密码、令牌或完整进程环境，不改固定端口或杀未知进程。重启安排在验收题之间；失败后按日志修正再执行，不盲试。

完成后报告所选环境、地址、检查和实际验收。就绪检查不调用模型，不能宣称自然语言成功率或耗时通过；模型题测需另行明确范围并记录费用。
