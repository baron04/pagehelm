# 芋道本地验收

正式入口在仓库根目录，不需要重新搜索历史任务或试运行器。

- 启动或更新：`./local`。固定地址 `http://localhost:48163`。
- 只读诊断：`./local status`、`./local check`。
- 故障日志：`./local logs`，基础服务用 `./local logs app`。
- 模型 `.env` 改动后：`./local restart`。结束使用：`./local stop`。

需要首次配置或错误含义时读取仓库 `docs/guides/local-yudao.md`。一般运行固定命令并检查最终退出码；只有错误指向缺项时才深入对应模块。

本地基础应用缓存固定在 `.q0-cache/yudao`，运行状态在 `.q0-cache/yudao-local`。原实例的 Compose 项目可由 Git 忽略的 `local.local.toml` 指定。不要改端口、创建带任务或日期后缀的缓存、从 `.workbench` 导入验收运行器，或为了启动环境恢复数据库、重置账号、运行 seed。

保留当前合成实例和数据。凭据只读取必要配置，不输出 `.env`、数据库密码、浏览器令牌或完整进程环境。端口占用时先辨认归属，不杀未知进程。重启发生在验收题之间；启动失败后依据日志修正一次，再运行固定命令，不反复盲试。

完成后报告地址、检查结果和实际做过的验收。就绪检查不调用模型，不能声称自然语言成功率或耗时已通过验收。模型题测需要另行明确范围并记录实际费用。
