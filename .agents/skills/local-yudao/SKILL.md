# 芋道本地验收

先读[本地指南](../../../docs/guides/local-yudao.md)。本地环境统一由目标源码目录的 `./local` 启动，环境选择、更新、诊断和数据工具按指南操作。

- 不接管其他源码目录正在运行的环境。
- 启动和排障时不额外恢复数据库、重置账号、填充数据或运行测评，不改固定端口、不终止未知进程。

交付时说明所用环境、检查结果和实际完成的验收。

运行冻结题集或恢复测评快照前，先读[工具约定](../../../.workbench/tools/README.md)，优先使用其中的测评运行器；手工运行时遵循对应清单。
