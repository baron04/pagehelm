# 芋道部署

先读[部署指南](../../../docs/guides/deploy-yudao.md)。部署实现放在 `examples/yudao/deploy/`，根目录 `./deploy` 是统一入口。

## 执行约定

1. 用户要求部署时执行发布并等待退出；仅优化流程或核验时用 `./deploy check` 或 `./deploy status`，不切换线上版本。
2. `deploy.local.toml` 缺失时先读模板，只询问缺少的配置；不推断 SSH 目标、不索要密码或私钥。配置内容及 Git 忽略要求见指南。
3. 缓存目录固定为 `.q0-cache/yudao`。
4. 模型密钥保留在服务器 `/opt/yudao/agent.env`。检查文件是否存在即可；不读取、回传或提交其内容。
5. 按最终退出码、发布清单和 Runtime 摘要核验成功；失败如实报告。结果不明时先用 `./deploy status` 确认版本，不自动反复发布。

发布不恢复数据、不填充测试数据、不删除数据卷；数据库升级和快照恢复仅在任务明确要求时执行。

健康检查只确认服务可用，不调用模型。助手功能需登录后另做验收。
