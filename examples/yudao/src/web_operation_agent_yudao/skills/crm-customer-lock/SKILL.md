# 锁定或解锁客户

**适用目标**：把一条既有 CRM 客户切换到用户明确要求的锁定状态，只改变锁定状态，不产生其他资料或权限变化。

**相邻目标**：容易混淆的目标是更新成交状态（独立状态动作，见 crm-customer-deal-status）；放入公海、领取（负责人和权限变化，见对应 Skill）；修改客户资料（资料修改不是状态动作）。公海动作的前置会检查锁定状态，但锁定本身是独立目标。

**所需用户信息**：确切的目标客户（完整名称或已核实候选）和期望状态（锁定或解锁）。

**利用当前事实的流程**：
1. 定位确切客户；同名时按 references/disambiguation.md 消歧，由用户选定。
2. 读取当前锁定状态；若已是所需状态，直接说明当前状态，不重复派发。
3. 核对当前账号 OWNER 权限；锁定上限由应用校验，超限如实返回。
4. 展示确切客户、状态变化和保留项，等待新的批准。

**完成条件**：批准后只派发一次，同账号回读确认锁定状态达到期望值、其他已读资料未变。权限不足或任一效果未证实保留不确定状态并停止，不自动重试。
