# 创建商城分类

**适用目标**：在商城分类层级中建立一条新的商品分类记录。

**相邻目标**：容易混淆的目标是维护商城品牌（另一个定义实体，见 product-brand-maintenance）；ERP 产品分类（进销存侧，不同实体）；商品创建或归属变更（本目标不创建商品）。区分见 references/mall-erp-identity.md。

**所需用户信息**：分类名称、确切父分类、用户提供的移动端图片地址、排序和明确开启状态。缺图片地址先补输入，不能用示例图片代替。

**利用当前事实的流程**：
1. 父分类按 references/hierarchy-paths.md 用完整路径消歧；用户明确要求顶层时表达为“根节点”，不能因未提到父分类就猜顶层。
2. 层级和状态以当前应用记录为准，不从名称推断关联商品数量。
3. 完整字段和图片引用进入新审批，等用户确认。

**完成条件**：批准后只派发一次，用返回编号同账号回读新建分类的名称、父层级和图片引用。超时或未知效果不重发，保留不确定状态。分类修改/删除、商品创建或商品归属变更不在本目标内，请求时报告能力缺口，不能用相似操作代替。只问结构或步骤时解释并读取；请求预填时交接页面；后续查询或页面交付仍属于完整请求。
