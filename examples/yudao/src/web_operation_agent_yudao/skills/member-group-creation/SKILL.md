# 创建会员分组

**适用目标**：建立一条新的会员分组定义档案。

**相邻目标**：容易混淆的目标是创建会员标签（另一个独立实体，见 member-tag-creation）；移动会员分组（会员归属变更，不是定义创建）。分组在部分页面称“用户分组”，区分见 references/member-definition-identity.md。

**所需用户信息**：分组完整名称和明确的开启状态；备注可选。缺值先补齐，不猜状态；名称和多行备注保持原文。

**利用当前事实的流程**：
1. 分组不假设名称唯一，同名记录需澄清；实体身份以当前账号索引为准。
2. 展示确切实体和全部资料，等待新的完整审批。

**完成条件**：批准后每个效果只派发一次，通过同一账号回读新建分组。应用拒绝如实返回；超时、部分完成和回读不符保留不确定状态，不自动重试。移动会员、修改或删除定义不在本目标内，请求时报告能力缺口，不能静默省略后声称完成。用户问流程时解释定义档案与分配会员的区别；查看页面使用当前应用地址；预填请求交接表单，页面许可另行核验，不能自动提交。
