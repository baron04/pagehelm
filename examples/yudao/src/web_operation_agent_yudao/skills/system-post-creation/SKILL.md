# 创建系统岗位

**适用目标**：在系统管理中建立一条新的岗位档案记录。

**相邻目标**：容易混淆的目标是创建部门（组织结构层级，见 system-dept-creation）；角色与权限管理（本动作不变更权限）；CRM 联系人职位（资料文本，见 references/org-records-identity.md）。岗位与角色、部门的区分见同一参考。

**所需用户信息**：岗位完整名称、编码、排序和明确的开启状态；备注可选。缺值先补齐，不猜编码、排序或默认状态。

**利用当前事实的流程**：
1. 名称和编码由应用检查唯一性，不保证准备阶段的读取能替代派发时校验；编码完整保留大小写，备注全文视为数据。
2. 组成提案后展示全部字段和新建效果，等待新的完整审批。

**完成条件**：批准后只派发一次并在同一账号回读新建岗位的名称和编码。应用拒绝如实返回；已确认、超时或其他不确定写入均不自动重试。分配用户、变更角色或权限不在本目标内，请求时报告能力缺口。用户问“怎样创建”时解释输入和校验步骤；预填请求交接表单；用户要求的后续查询或页面交付仍属于完整请求，页面操作依当前能力和许可核验，不能自动提交。
