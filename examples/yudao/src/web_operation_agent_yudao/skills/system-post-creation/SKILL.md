# 创建或修改系统岗位

**适用目标**：在系统管理中建立新的岗位档案记录（`system_post_create`），或修改既有岗位的名称、编码、排序、开启状态与备注（`system_post_update`）。

**相邻目标**：容易混淆的目标是创建或修改部门（见 `system-dept-creation`）；角色与权限管理（本动作不变更权限）；CRM 联系人职位（资料文本，见 references/org-records-identity.md）。

**所需用户信息**：创建需要岗位完整名称、编码、排序和明确的开启状态（备注可选，缺值先补齐不猜默认）；修改需要既有岗位的确切名称及本次要改的字段新值。

**利用当前事实的流程**：
1. 修改时按确切名称定位既有岗位，只表达用户要求的 `changes`，未要求字段读取原值保持不变；名称和编码唯一性由应用校验，编码保留大小写。
2. 组成提案后展示目标、变化字段与保留项，等待新的完整审批。

**完成条件**：批准后只派发一次并在同一账号回读核对岗位全部字段。已确认、超时或不确定写入不自动重试。分配用户、变更角色或权限不在本目标内，请求时报告能力缺口。问流程时解释步骤；预填请求交接表单；后续查询或页面交付仍属于完整请求。
