# 创建客户

**适用目标**：建立一条新的 CRM 客户档案记录，负责人为当前账号。

**相邻目标**：容易混淆的目标是在既有客户下新增联系人（目标产物是联系人，见 crm-contact-creation）；创建线索（线索与客户是不同实体，见 references/crm-erp-identity.md）；创建 ERP 客户（进销存往来单位）；修改客户资料（既有记录的变化，不是新建）。用户要求“新建客户并加联系人”时按完整请求选择两个已安装 Skill，用已有结果依赖引用新建客户；没有上层执行器。

**所需用户信息**：客户完整名称。可选资料（联系方式、地区、行业/等级/来源等）按用户原文提供，缺省不猜；用户指定负责人时需要其确切名称。

**利用当前事实的流程**：
1. 地区等层级引用按 references/hierarchy-paths.md 用当前树的名称或完整路径，行业/等级/来源等标签以当前字典为准，不猜编号。
2. 当前创建操作把负责人设为当前账号并为其建立 OWNER 数据权限；用户指定负责人时，将其名称保留在创建输入的负责人约束中，其他负责人的请求在写前拒绝，不能省略该条件后按当前账号建档，也不能用“创建”代替向另一个人转交客户。
3. 组成提案后展示全部字段、新建效果和权限连带效果，等待新的完整审批。

**完成条件**：批准后只派发一次，同账号按返回编号回读新客户的字段和 OWNER 权限；指定了其他负责人的请求未获支持即不称完成。用户要求的后续查询、打开档案或继续建档仍属于完整请求，不能省略；超时或无法核实保留不确定状态，不自动重试。
