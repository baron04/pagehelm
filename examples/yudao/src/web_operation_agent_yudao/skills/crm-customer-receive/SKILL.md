# 领取公海客户

**适用目标**：把一条公海中的 CRM 客户领取给当前账号，建立客户负责人、接收时间及 OWNER 数据权限并登记历史。

**相邻目标**：容易混淆的目标是放入公海（方向相反的独立动作，不是自动可逆对）；锁定/成交状态（独立状态动作）；修改客户资料（资料修改不建立负责人和权限）。公海是 CRM 客户概念。

**所需用户信息**：确切的目标客户（完整名称或已核实候选，需在公海中）。用户指定另一个领取人时，该名称保留在 owner 条件中并报告能力缺口，不能省略后领取给当前账号。

**利用当前事实的流程**：
1. 在当前账号可读的公海范围定位确切客户；同名时按 references/disambiguation.md 消歧，由用户选定。
2. 用当前事实核对前置条件：客户确在公海、未锁定、未成交；拥有上限由应用校验，超限如实返回。
3. 展示确切客户、领取效果（负责人、接收时间、OWNER 权限、历史）和不恢复联系人负责人这一边界，等待新的批准。

**完成条件**：批准后只派发一次；同账号回读核对客户负责人、OWNER 权限及联系人负责人保持未恢复。联系人负责人不会由本动作恢复，不能声称它自动恢复；任一效果未证实保留不确定状态并停止，不自动重试。
