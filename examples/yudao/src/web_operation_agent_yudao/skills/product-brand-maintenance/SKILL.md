# 维护商城品牌与营销活动状态

**适用目标**：建立或修改商城商品品牌档案（`product_brand_create`/`product_brand_update`），开启或关闭既有优惠券模板（`promotion_coupon_template_status`），以及关闭进行中的秒杀活动（`promotion_seckill_activity_close`）。

**相邻目标**：容易混淆的目标是创建商城分类（见 `product-category-creation`）；ERP 产品维护（进销存物料档案，区分见 references/mall-erp-identity.md）；修改优惠券面额/门槛或删除活动（本包只流转启停/关闭状态，删除未关闭秒杀活动会被后端拒绝）。

**所需用户信息**：创建品牌需要名称、用户提供的既有图片地址、排序和明确开启状态；修改品牌需要确切目标品牌和要改的字段新值；优惠券模板状态变更需要确切模板名称与目标状态（`开启` 或 `关闭`）；秒杀活动关闭需要确切活动名称（关闭不可逆，执行前须先向用户说明影响并取得确认）。

**利用当前事实的流程**：
1. 按当前账号索引定位确切品牌、优惠券模板或秒杀活动；同名时按 references/disambiguation.md 消歧，由用户选定。已处于目标状态时直接如实说明，不重复提案。
2. 品牌图片只接受用户提供的既有地址，不生成、上传或下载；修改只传用户要求的变化，其余已读字段保持不变。
3. 完整目标与状态/字段变化进入新审批，等用户确认。

**完成条件**：批准后只派发一次，用返回编号同账号回读核对状态或字段变化及未要求字段保持不变。关系或前值在审批期间变化即停止；超时或未知效果不重发。只问结构或步骤时解释并读取；请求预填时交接页面；后续查询或页面交付仍属于完整请求。
