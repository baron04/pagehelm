# 维护商城品牌

**适用目标**：建立新的商城商品品牌档案，或把用户明确要求的变化落到既有品牌上，其他已读资料保持不变。

**相邻目标**：容易混淆的目标是创建商城分类（另一个定义实体，见 product-category-creation）；ERP 产品维护（进销存物料档案）；修改商品归属（本目标不变更商品）。区分见 references/mall-erp-identity.md。

**所需用户信息**：创建需要品牌名称、用户提供的既有图片地址、排序和明确开启状态；修改需要确切目标品牌和要改的字段新值。缺图片地址先补输入，不能用示例图片代替。

**利用当前事实的流程**：
1. 修改时按当前账号索引定位确切品牌；同名时按 references/disambiguation.md 消歧，由用户选定。
2. 图片只接受用户提供的既有地址，不生成、上传、抓取或下载；修改只传用户要求的变化，其余必填资料由应用读取并作为保留项。
3. 完整字段和图片引用进入新审批，等用户确认。

**完成条件**：批准后只派发一次，用返回编号同账号回读全部效果；修改还核对未要求的已读字段保持。关系或前值在审批期间变化即停止；超时或未知效果不重发，保留不确定状态。品牌删除、商品创建或商品归属变更不在本目标内，请求时报告能力缺口。只问结构或步骤时解释并读取；请求预填时交接页面；后续查询或页面交付仍属于完整请求。
