# 客户放入公海

**适用目标**：把一条有负责人的既有 CRM 客户释放进公海，客户和其全部关联联系人的负责人被清空，客户全部 OWNER 数据权限被删除，负责人历史由应用登记。

**相邻目标**：容易混淆的目标是领取公海客户（方向相反的独立动作，见 crm-customer-receive，两者不是自动可逆对）；修改客户资料（资料修改不能产生公海效果）；锁定/成交状态（独立状态动作）。公海是 CRM 客户概念，ERP 客户无公海。

**所需用户信息**：确切的目标客户（完整名称或已核实候选）。无需其他输入；本动作不可用于转移给指定负责人。

**利用当前事实的流程**：
1. 定位确切已有客户；同名时按 references/disambiguation.md 消歧，由用户选定。
2. 用当前事实核对前置条件：客户尚未锁定、当前有负责人、当前账号持有 OWNER 权限；不满足时说明状态，不派发。
3. 展示确切客户、完整连带影响（客户与关联联系人负责人清空、OWNER 权限删除、历史登记），等待新的批准。

**完成条件**：批准后只派发一次；写后用当前账号的公海列表、完整关联联系人列表和权限列表核对全部可观察效果。失去详情权限时按公海列表与联系人关系核对，不能把“查不到详情”当作成功，也不能换管理员核对。任一效果未证实保留不确定状态并停止，不自动重试；第一次派发结果不确定时不能调用领取来“撤销”。
