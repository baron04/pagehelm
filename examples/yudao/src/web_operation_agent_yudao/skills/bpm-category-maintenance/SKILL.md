# 创建流程分类

**适用目标**：建立一条新的流程分类记录；查询与页面定位支持该目标。

**相邻目标**：容易混淆的目标是创建流程模型、部署流程或发起流程实例（流程分类只组织流程定义，创建分类不创建模型、不部署流程、也不发起实例）；查询模型或实例必须另读对应实体，不能从分类存在推断流程已可运行。

**所需用户信息**：完整名称、编码、排序和明确开启状态，描述可选。缺值先补齐，不猜编码、排序或默认状态。

**利用当前事实的流程**：
1. 名称和编码由应用检查唯一性；编码保持大小写，描述全文是数据。
2. 查询保留请求的条件与字段，通过当前账号的索引及记录回答；页面地址取自应用。名称或编码不明确时澄清，不能任选分类。
3. 执行前展示全部字段与新建效果，等待新的完整审批。

**完成条件**：批准后只派发一次并由同一账号回读。应用拒绝如实返回；超时或其他不确定写入保留审计，不自动重试。修改、删除、批量排序、创建模型、部署或发起流程需报告能力缺口，不能把所需效果改为创建分类。只问操作流程时说明输入、唯一校验和保存步骤；要求预填时交接表单，页面操作依当前能力和许可核验，不能自动提交。
