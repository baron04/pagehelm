# 更新客户成交状态

**适用目标**：把一条既有 CRM 客户切换到用户明确要求的成交状态，只改变成交状态。

**相邻目标**：容易混淆的目标是锁定/解锁客户（独立状态动作，见 crm-customer-lock）；放入公海、领取（负责人和权限变化）；修改客户资料（资料修改不是状态动作）。本动作不创建合同、商机或实际回款，不能宣称产生了这些业务对象。

**所需用户信息**：确切的目标客户（完整名称或已核实候选）和期望成交状态。

**利用当前事实的流程**：
1. 定位确切客户；同名时按 references/disambiguation.md 消歧，由用户选定。
2. 读取当前成交状态；若已是所需状态，直接说明当前状态，不重复派发；应用拒绝重复状态时如实返回。
3. 核对当前账号 WRITE 或 OWNER 权限。
4. 展示确切客户、状态变化和保留项，等待新的批准。

**完成条件**：批准后只派发一次，同账号回读确认成交状态达到期望值、其他已读资料未变，且未创建合同、商机或回款。权限不足或任一效果未证实保留不确定状态并停止，不自动重试。
