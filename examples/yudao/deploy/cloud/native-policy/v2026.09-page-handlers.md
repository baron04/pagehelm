The policy is server configuration and never model context.

Navigation still requires an actor-readable menu or record address and rendered route/readback. Tabs require the exact selected tab on the same record. Query inputs require the current field/form identity and exact applied query digests. Form entry names exact buttons; scalar inputs use live form preparation. Date/line steps bind one transient command, current form identity and readback. Adding a line preserves the DOM form lifetime while changing its structure. No submit, upload, delete, workflow or persistent handler is included.
