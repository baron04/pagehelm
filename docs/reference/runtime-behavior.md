# 运行时行为详情

本页保留通用合同；仅处理芋道时再读[芋道运行时](yudao-behavior.md)。设计与接入见[系统设计](../concepts/overview.md)、[Adapter 合同](../guides/integrate-an-application.md)、[Skill 与工具](../concepts/skills-and-tools.md)、[持久运维](../guides/operate-durably.md)。

## 覆盖与限制

- 接口仍为 alpha；未实现跨主机扩缩容、活跃任务迁移或跨主机撤销。应用提供可信身份、委托凭据、授权映射及业务后置条件。
- 浏览器不提供数据库事务或回滚；不确定写入须应用读取和人工裁决。Odoo 页面守卫不隔离外部副作用、其它会话、自定义请求中途提交或窗口关闭后的客户端重试，不是通用写入沙箱。
- 已实现路径和合同测试不证明总体准确率或优于其它 Agent。现有评测规模有限、部分由实现者出题，限定见[Odoo 评测](../../evals/odoo/README.md)和[芋道对照](../../evals/yudao/tool_loop/RESULTS.zh-CN.md)。源码辅助无 Skill 预填仅有脚本合同检查，无独立真实模型成功率；Chromium 覆盖最强，其它引擎/读屏器未全面验证。
- 源码检索可匹配中文标签/注释，不自动翻译英文标识符，跨语言召回未充分验证。托管模型会收到检索出的 allowlist 源码，部署数据政策须允许。

## 已实现能力

### 目标与读取

目标式回合由模型对照当前 actor 索引声明，服务端解析：名称搜索记录、类型化读值、限定范围统计、审核路由导航、可见名称选页签、应用状态核对筛选/分组、控件高亮交接；答案采用读回值。全部声明落实才完成，缺项须说明、歧义须追问，指名记录不存在不改新建。数字/文本可比较，日期支持日/月/年、区间、命名时段并按用户时区计算。模型仍可能选错实体/字段/范围，并增加调用和时延。

页面先 `set_target`，新观察核对后由程序生成到达措辞；只证明声明中的路径、控件、筛选/分组，不证明异步加载或遗漏要求。列表自由文本搜索走限定读取，不填页面搜索框；空读交回 Agent，不直接断言不存在。

实体读取可发现 actor 可读实体并有界查询；记录引用按名称/编号返回候选，不代选。`find_page_entries` 按当前 actor 页面/动作元数据排序候选，仅为审核过的独立目的地返回路由；`resolve_goal_candidates` 一次最多组合三个问答/页面/交接候选，均不表示目标完成或全页面覆盖。实体读取合同由 Odoo、Contacts REST 共测。逐步 Agent 可搜索/翻页当前有界脱敏观察，不查询应用数据，也不证明不存在。

### 页面、表单与权限

当前视口最多暴露 200 个可操作控件，动作按新观察/路由策略准入。每问首次页面操作（导航、点击、填写、选择、提交、返回、筛选）须可见同意卡，本轮沿用；下一问或工具循环修订任务理解后重征求。读取、滚动、等待、高亮免征求；页面同意不能代替业务写审批。

- 核心默认关闭可能写入的浏览器动作（含导航），应用显式开启审核子集。点击策略可局部放行；Odoo 仅放行审核页/记录链接、页签、主页及具名视图切换/翻页/搜索/菜单，拒绝工作流、新建、操作、选行、行内编辑与未审核页面。
- `goto` 已在当前地址则保留文档；跨页优先 `openPage`，应用不能接管才加载文档，仍须渲染核验。页签初始回执加载中可等稳定观察经应用核验后结束。
- 有页面只读守卫时可列最多 32 个筛选/分组选项，`apply_facet` 以新观察的生效状态为准；页面查询能力须显式开启。目标式高亮最多展开三个页面声明的折叠菜单，不选菜单项，并说明位置。
- `page_write_guard` 可令操作期间应用会话只读；Odoo 须先部署 `woa_runtime` 1.5，再部署 Adapter，窗口内每请求用只读事务。`observe` 不开启/续期窗口；其它动作仍检查窗口。数据工具后新观察失败以 `page_observation_failed` 结束，记回执错误并提示刷新重发，不重试写。
- 预填默认关闭，须审核端口与 `allow_form_prefill=True`；只填用户给值，核对实时字段并高亮提交，无法确认的值留给用户。无 Skill 标量兜底为 `describe_form/prepare_form/prefill_form`。Odoo 新建表单离开会自动保存，故拒绝通用手动提交预填；类型化客户新建/编辑交接须写确认通道和新审批。交接仍须对应当前表单，成功提示人工核对提交，失败/待补充不报完成，不附离开草稿的入口。
- `highlight` 只指当前可见具名控件，不点击、不证明业务完成。提交指示绑定本轮答复与确切控件，不可见/不可用则提示，目标失效/换页/新请求清除；状态仅留浏览器。跨 iframe 沿用高亮，命中采样不保证识别不接收点击的遮挡层。

写入默认关闭。只有完整用户请求能表达执行意图；Skill、范围、工具、页面或记录文字不授权，意图仍可能误读否定。启用后绑定确切效果/对象、新鲜完整可见审批、一次消费/派发及应用核验。actor/tenant/workspace 主体可绑定 capability、scope、审批、mutation、审计与撤销。超时或核验不完整记 `indeterminate`，不自动重试。

应用能将确切提案映射到当前 actor 暂存表单时，可提供“只填到表单”审批第三项，绑定摘要、操作上下文、目标页/字段；未提供则拒绝，重复/冲突按同一批准编号处理。保存/预填同一可见门槛。选择后消费卡并允许交接所需页面动作，撤下本轮写工具，仍走页面准入/回执核验，不派发业务写，失败即停。Contacts REST/HTML 新建联系人已有真实浏览器检查；芋道只开放受限联系人提案。

## 执行器与集成细节

### 决策、结束与源码

同一 Agent 每次决策前收到工具结果和新观察；公共循环核对闭合 schema、类型化结果及应用签发的一次性动作/暂存授权，受步骤/时间/token/模型花费预算约束。`AgentTurnConfig.data_reads`、`action_policy`、`require_page_route`、`require_task_contract` 默认关闭，须显式开启且不授写权。上下文按当前页面、有界历史、当前 Skill、惰性源码各自职责组装。

- 模型决策与实际工具分别限额，一回复多工具不能越过 `model_steps`，用尽后只总结已核实事实。相同页面状态/参数重复点击、输入、选择、滚动或填字段会拒绝，第四次未完成结束；观察轮次/临时 ref 不算进展，成功重读列表算状态变化，无变化滚动会明示。
- 同来源连续两次空读提示检查筛选，四次后停止读取、只总结已核实事实；非空读重置计数。唯一控件三次因未审核被拒即结束，无关搜索不重置，每次仍重审，不合并歧义控件。
- 中间文字不交付，正文须 `finish.answer`；无工具回复标未交付并替换后续历史原文，原始脱敏轨迹仍留存。两次协议纠正后仍无工具则未完成，不以中间文字兜底或额外启动完成复核。答案按实际交付预算声明，不静默截短。
- 写关闭时不做模型完整请求复核，程序检查只纠正/补足答复，未执行页面步骤在答复后列明；同参只读失败不再执行，第三次结束并交付已读结果。写开启时保留工具要求的复核，最多纠正一次，不可用/仍分歧不报完成；模型复核非确定证明。普通结束为 `not_claimed`，局部核验不证明整个请求/答案正确。
- 应用可为 `agent_refused` 页面失败提供有界终止说明，保留字段问题/未完成范围；不覆盖权限、传输、派发状态或不确定写，不触发重试。

源码仅答明确实现问题；业务值/配置读应用，不取源码默认值。可选 allowlist 检索、有界行读取/Git 历史；结论须本轮引用及原文支持，程序标源码版本。纯源码查无依据后的拒答由服务端说明来源/边界；引用校验不证明语义。纯源码无需浏览器/业务元数据，调用应用工具前须绑定请求页真实观察。编译图谱可附显隐/禁用、必填/只读及方法拒绝规则并引准确行号，组织用语须审核；普通操作不要求源码。

### 结构化交付与计算

`StructuredQueryAnswer` 由程序排版值并签发仅本轮有效的 `finish.read_answer`，模型先看结果再引用。请求后，`done` 须选一份完整结果且 `answer` 为空；缺/跨轮引用、来源不完整、预算不足不能完成，可用 `cannot` 说明缺项。每轮留最近四份候选，引用不授权。`actor_digest/record_ids` 须同时提供，ID 唯一不可变且逐行对应，结束复核账号，元数据不改正文；旧调用可交付文本但无原生身份保证。

投影上限：5,000 行、20 列，键限字母数字下划线，单值 1,000 字符、总值 100,000；不提高原读取上限，最终正文仍受预算约束，不截成“完整名单”。未读全、重复 ID、类型未证实、缺字段或超预算不能完成；保留来源、实际条件、命中数、缺值/并列说明。一引用可含同集合多统计，不自动满足跨集合/页面/解释义务。芋道分页 API 和 Contacts REST 共测；模型仍负责选择接口/范围/条件/字段。

通用汇总只接同账号已读全的有界集合，Adapter 提供行/类型/单位/范围/完整性；模型声明条件、分组、计数/去重计数/合计/极值/排名。十进制计算，不执行表达式；文本保留空格/大小写，日期显式类型、时间阈值带时区。`between` 含两端，自然时段含起点、不含下一起点，保留末秒小数。关联按编号分组，同名不合并；缺字段/null/空串/0 区分；空集合合计 0，非空全无有效数值则为空并说明。第 N 位保留全部临界并列，不取 N 种不同值。

`display_name/labels` 只排版，不改类型、比较、排序、计算或分组身份；字典缺非空代码保留代码并说明，未声明字典不推断，null/空串仍缺值；合计/计数不套标签，极值保留列标签，标签计入预算。等价声明可规范化并说明：`==/<>/ge` 等运算符、非英文标识符别名转 `m1` 等；`count(id)` 计记录，其它列计非空；数值列数字字符串、关联编号整数、文本列整数、布尔列 `"true"/"false"` 按列类型归一，其它不符拒绝。程序保证指定输入的计算/交付，不证明模型选中了完整用户意图。

### 实验性 Skill 规划

Skill 为 YAML 元数据/Markdown 正文及有界按需附件，资源工具只读已加载包可读文本，正文已加载；当前事实以应用读取为准。独立注册工具定义能力、actor scope 和效果，已注册读取不要求匹配 Skill。`agents/woa.toml` 审核身份只选知识、操作清单只限提案，不安装工具/授权；schema 按写开关/actor 权限过滤，派发再校验。

安装 `ToolDefinition.effect_contract` 且启用写后，默认 `complete_request_check="single"` 从完整请求提已安装操作、锁定应用效果。范围调用可同时 `select_skills` 选 1–4 身份和 `declare_scope`，两者均校验；范围只定位，不强制步骤。路由结构错误准备前纠正一次。普通查询/页面/准备/源码保留原解析器；写关闭/无效果合同保留原准入和恢复。普通目标可在变更、拒绝或源码出口前征询执行一次，未要求执行/无匹配操作可批准前让渡；范围无效时无源码恢复完整索引，有源码保留依赖拒绝。纯源码可能多一次选择调用。合成检查不证明真实模型成功率；实测 Token Plan DeepSeek 端点按供应商 `auto` 编码要求工具，客户端仍拒绝无工具响应。

同一 Agent 可读获准工具/已加载附件；读取与提案/结束同返时仅执行读取，看结果后重提，已接受步骤和预算不变。提案须工具响应及显式非空结束。首审批前检查 schema、原文来源、依赖、已声明查询/页面能力和独立准备效果；schema/来源/只读准备共用一次纠正，可补读再替换失败操作，耗尽保留失败，不隐式让渡。规划 schema 含不透明 ID/动态过滤、本地解析引用；应用仍验身份/语义/权限。实体/字段只用已返同一 Agent 的 ID；先描述实体才用其已返字段，仅收窄规划。

规划封装 `{"request_intent":"execute","inputs":{...}}` 的原样输入绑定完整原文；显式保留放顶层、只用应用字段身份，普通 patch 保留由应用负责。单提案 `declare_goal` 只声明读/页面/预填、`write_intent=false`，执行声明占既有一次纠正。准备投影真实效果、身份、保留输入、默认/复合效果，绑定审批并核对锁定请求；回执覆盖全部必需效果才记 journal 完成，否则不确定且不重试。检查不能独立识别字段交换/遗漏。

可选 `complete_request_check="anchored"` 同 Agent/预算内并行独立解读动作/目标/用户事实，不看 schema/草案、不声明字段；与效果草案及独立读/页面义务比较，分歧允许准备前一次整任务重声明。两份解读共用 Skill；值一致不证明字段身份或可靠性。

范围先用 actor 可见实体名；已提实体且无单据编号时，名称在声明后仅于该实体及关联实体定位，编号/无实体名仍全局引用查找；延后不证明不存在。复合读取涵盖当前工具声明的审核关联实体；初始候选非完整查询。`single` 引用准备错误可占共享纠正补读，仍歧义则写前给完整显示名候选；回复后重声明/新审批。权限失败不纠正，无候选的缺失记录保留拒绝；已派发/不确定不重试。页面定义源码仍属知识请求，可与执行 Skill 同路由选择、保留实时依赖；选择不授权。

### 答案链接、面板与会话

只读工具可签发页面/记录链接，仅附完成读取中、名字出现在答案的唯一目标；重名、跨域、带查询/片段、未完成或写入回合不附。Contacts 用 actor 页面目录/二次联系人读取签发。用户点击时，浏览器本地查表单/对话框/未保存值：无草稿且有 `openPage` 走应用路由，否则新标签；路由拒绝由预留标签承接，草稿状态不送服务端。

面板只呈服务端状态，脚本启动即有按钮；打开/发消息建会话并恢复当前账号历史，空闲五分钟释放，下一消息恢复。新文档首次握手遇已关闭且无待决任务/动作/审批/回执时可从配置启动端点重取一次，不重发消息/动作；失败说明并供重试。可选 SQLite 提供所有权、outbox、有界上下文、journal、备份及人工结算。

同会话多页共享历史，仅发起页执行/收指令；任务中提示等待、保留历史，服务器接受新会话才清本页，旁观页不关执行页保护窗口。刷新/跳转保留展开状态并恢复历史；审批过期撤卡/恢复输入/保留重发说明，不延用。旧记录加载保持阅读位置，可回最新；示例仅填草稿。浮层/抽屉形态和位置存本浏览器，收窄页面/遮挡应用弹窗须接入验证。最终 Markdown 仅封闭语法显示标题/强调/列表/表格/引用/代码，HTML/图片不执行或加载，链接限会话允许来源。
