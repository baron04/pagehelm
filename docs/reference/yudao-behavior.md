# 芋道运行时

本页只补充芋道原生宿主；通用审批、循环、结构化交付及限制见[运行时行为](runtime-behavior.md)。配置入口见[部署说明](../../examples/yudao/deploy/README.md)，工具阶段合并见[执行器](../concepts/executors.md)。

## 宿主、身份与开关

定位绑定通过当前 Vue 页面实际渲染的控件更新与联动回调操作，不把组件识别当作动作权限。当前只支持已渲染的查询控件、页签、分页和带唯一数字编号的普通平面表格；树表、展开行、虚拟行或无法唯一关联的数据不据行号猜记录。日期范围通过当前挂载 ElDatePicker 的原生范围回调更新，并保留组件格式化及 update/change 联动。标准 `daterange` 尊重应用的默认端点时间；查询区 `datetimerange` 接受完整的 `YYYY-MM-DD HH:mm:ss` 并保留时刻，仅给 `YYYY-MM-DD` 时沿用起止自然日均含的查询口径，明确归一为起日 `00:00:00`、末日 `23:59:59`，这不是无 `defaultTime` 控件的页面默认时间。带默认时间的标准日期时间范围通过自身时间编辑及确认回调保留查询时刻。此规则只用于查询，不扩展业务表单的预填权限；无效日期、时刻或反向结束值拒绝，不以普通输入回退报告成功。修改已有范围先等原生打开基线落定，再选值，保留 change 联动及未修改端点的实际时刻；未知结构保留普通路径的真实记录。`filter_page` 的已知查询下拉使用两次共享准入的点击：展开当前 combobox，重读后点击同属其 listbox 的唯一精确选项；随后核对实际选择。普通 select 回退保留。查询筛选不另设值来源门槛；业务表单预填仍保留来源校验。查询框在当前列表的屏外区域时，定位程序会从最新观察选择滚动区域、滚动并重读后再解析控件；查询区和分页都在屏外时也可使用当前绑定行定位区域，候选暂缺时先做一次有界重读；未观察到或未挂载的字段保留未核实，不据此断言页面不支持。缺候选时仅向私有 audit 记录有界控件元数据及标签摘要，不含输入值，也不改变页面观察、正文或动作授权。排序、换页或行替换后，浏览器重新核对记录身份和可见业务值；每次查询仍以应用自己本次成功请求的序号、参数及实际行核验。记录详情通过当前唯一行实际渲染的记录名链接或详情控件点击打开，随后核对页面或弹窗中的记录身份；声明的详情地址不是点击的前置条件。原有普通工具完整保留，仍受共享准入和业务表单来源边界约束；动作回执分别记录绑定与普通路径。此开关本身不保证所有应用 GET 都只读，部署的写围栏仍须生效。

芋道原生宿主的单轮总执行时限为 120 秒；超时会结束本轮并显示失败状态，下一条消息可开启新一轮。该时限包含模型和页面操作，审批等待按通用合同暂停计时。

原生宿主只用应用无关 `ModelDrivenTurnExecutor`（`slim`）；旧 `goal/page-agent` 参数拒绝，不回退。启动须版本匹配的 v2 方法围栏及带审核路由/处理器的 `--native-page-policy`，live forms 与应用只读窗口始终启用；缺失/不兼容在模型和网络启动前拒绝。接口工具也不调用围栏拒绝的 GET，浏览器提交始终关闭，业务写默认关闭。

模型逐步选当前账号菜单、只读 API、Runtime 页面工具；`--native-writes` 开启后才可 `load_skill`，加载操作成为带安装 schema 的工具。写入沿共享链路：同账号只读准备、登记字面输入逐字对照用户原话、准备效果核对、完整可见审批、单次派发、同账号回读。审批前拒绝可在同一对话内有限纠正；取消审批、应用拒绝或不确定写入结束本轮，不重发。目标式 Skill 选择/单提案/让渡不用于 slim。

| 配置 | 效果与边界 |
| --- | --- |
| `native_writes=True` / `--native-writes` | 开启原生类型化写，仍须匹配 Skill、审批及同 actor 回读，不开放浏览器提交。 |
| `location_bindings=True` / `--location-bindings` | 默认关闭。提供一次导航、切页签、填查询条件并搜索的 `filter_page`，以及 `page_section`、`page_number`、按当前表格编号或精确列值认行的 `open_record`。不能同时开启业务写，不填业务表单。每个底层动作仍经过已有页面同意、准入和交付核对。 |
| `native_page_admission="method-fence"` / `--native-page-admission method-fence` | 普通控件可以在缺少逐页登记时操作。仍核对当前账号、可见目标、观察时效与应用页面状态，遵守显式禁用与扫描排除。助手拒绝点击已识别的提交、审核、删除等写控件，页面守卫拒绝写方法和扫描登记的全部写型 GET。默认 `reviewed` 保持审核准入。 |
| `native_page_admission="read-only-window"` / `--native-page-admission read-only-window` | 仅供显式选择的隔离只读窗口使用，不能同时开启业务写。须运行并验证方法围栏，拒绝写方法和全部登记写型 GET；页面同意、账号/会话、同源、最新实际控件及已识别写控件的拒绝仍生效。此模式不以路由、处理器或控件登记及禁用清单审计普通动作；业务表单预填保留共同校验。默认 `reviewed` 与已有 `method-fence` 行为不变。 |
| `--native-page-disable <handler>` | 可重复传入 `query/paging/fields/lines`；Python 为不可变 `native_page_disabled_handlers`，默认空。在 `reviewed` 和 `method-fence` 下关闭优先于菜单/路由许可，同时收紧能力、参数和准入；不影响 API 条件问答和行表查询。`fields/lines` 均关时仍可开审核表单供人工填写。 |
| `--no-native-edit-prefill` | `native_edit_prefill=False`，只允许有实时新建证明的预填。通用宿主默认保留编辑预填，本地验收入口显式关闭；编辑表单仍可打开并给人工建议。 |
| `--runtime-source` | 默认关闭用户态源码工具。`--source-root` 版本仍在启动校验，构建扫描仍由 CLI 读版本树；仅显式开启才给模型检索/行读取/Git 工具。 |

会话建立/续期先用页面访问令牌核实身份，再读写工具所需字典；任一步 401 保留原状态，由 loader 用应用刷新令牌续期并重试一次；403 保留权限拒绝，上游读取故障为 503，不触发刷新。身份未核实不建新会话、不派发业务操作。原生 API 页面代理对失效身份在派发前拒绝，采用应用的 HTTP 200、`code=401` 促前端续期；批准接口仍为 HTTP 401。续期成功取决于应用刷新令牌。

跨轮只保留用户原话、各轮答复和已核对写入，默认最近四轮、32 KiB，按会话持久化；宿主重启可续聊，历史页面/数据须重读。默认后台预热该用户菜单、API 说明及 outline，不读明细，量随模块变化。冷启动测试可关预热，生产 CLI 无此开关，预热不代表冷启动性能。当前仅小规模合成评测。

接口/名称查找结果交模型前隐去从不读取的密码/密钥/令牌/渠道配置、凭据命名配置项的值，以及字符串里的凭据/会话参数赋值；其它 actor 可读业务字段不遮蔽。数据行、值、名称围为应用事实而非指令。服务端时间线在动作间说明查页面/来源/记录、读取列表及行数、准备更改/核验结果。实际工具上限目前 `model_steps=24`。

`native_write_preparation`（CLI `--native-write-preparation`）默认关闭。开启后复用既有 Skill 提案、表单准备及交接工具，实际 `native_writes` 仍关闭，且不能同时开启定位绑定。准备仍核对账号、目标、业务值来源和原有批准语义；即使收到有效批准，业务运行时及底层注册表也拒绝派发，提案不成为已执行变更。可与 `read-only-window` 同用；默认配置及 `native_writes` 与该档的原互斥保持。此选项不放行页面提交或写型 GET，也不改变浏览器和接收围栏。

## 页面准入与核验

当前部署菜单和已知记录路由只证明目录归属。默认审核模式按级别放行菜单页和记录详情的导航、查询、分页及页签，开表单、填字段和加行需要逐路由审核。选择方法围栏准入后，普通控件可用当前页面和账号的实际证据代替登记。已审核动作的业务结果仍按原规则核验，临时表单仍由用户提交。发布扫描逐页导航并执行查询、重置、分页、页签和开表单，将观察到写入及完全无源码或数据表的路由排除。两种模式都遵守排除与只读窗口，已识别的写控件由助手拒绝操作。

原生导航优先当前文档 Vue Router，保留助手、历史和应用实例；应用不能接管才整页加载，同地址保留文档。不因已有弹窗/抽屉强制刷新：页面表单随旧组件卸载，布局弹窗保留；目标仍须可见可用，弹窗未消失不算到达。

| 场景 | 必须核对 |
| --- | --- |
| 当前页 `blocked` 后离开 | 只接同源、属于 actor 菜单/详情且未排除的确切目标；`pending`、当前页控件、排除目标仍拒绝。目标就绪及渲染路由证明后才成功；`invalid_target` 不证明不支持/无权限。 |
| 查询/重置 | 新一版成功列表读取，当前可见查询值与参数摘要一致。浏览器省略空文本 `value` 按空核对；未显示字段变化不确认。筛选字段须先观察，折叠字段先用审核展开按钮。 |
| 列表页签 | actor 菜单、已渲染列表、成功列表读取均存在；页签实际选中，同一接口以不同参数成功重读。 |
| 详情页签 | 当前记录及实际选中；仅用户给 ID 或 actor 名称搜索证实唯一时可直接结束。否则写开启时做完整请求复核，最多纠正一次/复核两次，不可用或仍疑则不报完成；写关闭不做模型复核。 |
| 分页批次直接结束 | 当前列表回读的每个页码/页大小均符合，并绑定本次确切核验命令。 |
| 部门树（系统用户） | 仅视口内属于原生选择器的节点/点击区域，同名带层级路径。选中状态与新版列表读取一致，核对 `deptId`、其它筛选、页码/页大小；再次点已选节点会取消。树名称框只搜节点，不作为用户列表筛选。 |
| 查询下拉/日期范围 | 当前页选项标签绑定原生标量并核验查询；日期仅在输入框所属弹窗内定位，目标不在双月面板时有界前后移月再核对，不能确认则拒绝。 |

可见表格行提供有界“列名=值”。`call_api` 可附同 actor 实体索引绑定的部署列名/字典，详情只复用同实体；未知接口/冲突不套其它实体。空结果可带合法代码含义；接口发现可附同一原生搜索表单的固定选项/当前字典名，只展示已发布查询参数；无源码、动态选项、冲突则缺省，不猜状态码、不增参数或权限。接口与当前页读取路径相同可附本页列名；元数据不证明页面打开，实时观察优先。

导航用 actor 实体/页面 outline，动作前后精确读目标详情，不编译无关内嵌明细。最后页签点击可携答复，但仅确切动作经保护/核验、同 ID 页签实际选中才结束。明确只问业务状态、没有页面/金额核对/修改要求时只给查找/API 工具，页面动作拒绝；混合请求保留原工具。提示词把“看记录/详情/页面”解释为导航，“看字段/数量/金额/有哪些”解释为数据，两者同问分别完成；只是模型规则，不保证正确分流。

## 读取与交付

### 范围、权限与失败

`call_api` 用当前账号调用已发布只读接口，保留查询参数原义，不暗添/替换负责范围。CRM 无 `sceneType` 读普通列表，明确“我负责/参与/下属负责”才传对应参数；页面筛选以当前页签/视图为范围，空结果如实返回，不跨范围或断言不存在。普通列表字段可读不证明详情/编辑资格，详情拒绝也不抹掉已读列表值。

`find_record` 仅按名称；名称查空不证明 ID/业务编号不存在，编号须用已发布 API 对应参数。唯一命中返回实际已读编号；全局未命中说明索引边界并附相关接口元数据，均不证明不存在。客户在三个负责范围未命中会用普通名称列表补候选并验详情；仅客户已审核的范围语义可返回范围外的类型化权限拒绝。联系人将范围候选与普通列表同名候选合并去重，新增候选须详情 GET 验身份/权限；读取失败保留原拒绝，不由列表可见推断无权打开。预览只传接口声明参数，需要额外输入则跳过。按列读取列出已返回、有文档但未展示的列以供补读。

slim 的确切 API 拒绝只归该接口，不结束整轮或推断其它接口/目标无权限；页面准入拒绝也只归该动作，两者均说明已读结果仍有效。只有指向记录/数据本身的确切读取拒绝才能据以说“无权限/读不到”。类型化数据权限拒绝、身份失效、写入拒绝仍按各自边界结束/拒绝；接口结构纠正仅报已安装字段，不回显被拒输入。每读都由应用认证授权，凭据失效/改变拒绝继续，表单/写入另核权限。动作回执保留错误码/派发状态，审计脱敏，等待不覆盖已确定结果。

客户详情编辑资格只针对客户；请求改关联联系人不查/回传客户编辑资格，从联系人详情改则验联系人权限行，不靠编辑控件可见推断。资料不足先问、不猜。跨轮可借上轮单号等唯一标识定位，但须重读；金额须同记录页面核对，不复述历史。页面数值只证当前可见记录，对话框开时不读底层列表、不补观察外值。

### 行表、计算与逐项交付

`call_api` 把实际读到的行放入本轮私有行表。带 `fields` 时最多读取 5,000 行；只有从第一页开始、应用总数有效稳定、ID 跨页不重复且实际读足总数，才标为完整。多页读取没有同一时点的快照。行表保留原生字段、空值及重复名称，不含凭据字段；已审核金额按部署策略保留页面显示单位。

`tables` 列出本轮的表、接口条件、实际行数、应用总数和完整性。`sql` 只在这些内存表上运行一条只读 SQLite 查询，返回至多 200 行并明确标注截断。应用总数不等于实读数；行表未读全不能据此交付完整名单或全量统计。应用按已发布参数取数；模型可在行表上核对返回行是否满足用户条件，不能假定提交了参数就等于筛选已生效。

`date_range` 按应用日期与时区换算日、周、月、季度、年，提供起止日期及毫秒时间戳。已发生事项的本周、本月、本季度和今年默认截至当天。计划与预算用 `scope=planned` 覆盖完整自然周期。近 N 天含当天共 N 个自然日，使用 `unit=rolling_days, days=N`，最近一个月按近 30 天，上个月按上一自然月。用户明确起止日期用 `unit=range`、`start_date` 和 `end_date`，首尾均含，优先采用明确范围。模型按业务字段语义把日期范围写入实际查询，相对时间工具本身不读取业务数据。

结束时，模型把给用户的正文写进 `finish.answer`，在 `items` 逐项填写交付内容、状态与本轮回执编号。程序退回不存在、跨轮或含凭据的引用及交付；回执只证明工具实际返回的内容。模型仍可能选错范围、字段或算法，正文也可能漏项。行表和回执不会跨轮复用。

定位、记录详情、页签、树节点和列表筛选的结果须落在用户页。交付项用 `kind` 区分数据、页面和写入。页面项引用本轮成功观察产生的页面状态回执，交付时页面状态须与回执相符，不强制另有 API 或记录查找回执。默认交付页面；弹窗本身是交付对象时可声明 `container="dialog"`，或使用已核验的表单交接。残留弹窗遮罩不能充当已落定页面。筛选还需核对应用实际请求条件和当前可见行，缺少其中一项证据时说明核验缺口。部署的动作准入继续决定可用范围。退回次数按检查原因和单项保存，失败集合缩小或组合变化不重置；同一检查对同一交付项最多退回模型一次；再次不通过、无法继续请求模型或预算不足时，把受影响项和本轮标为未完成，答复说明未核实项。

答案链接由当前账号菜单签发唯一页面目标、同账号详情签发唯一记录目标；只读完成、答案同名及浏览器草稿检查等条件仍按通用合同。

## 金额、源码与答案核对

可选逐字段金额策略把接口列、路由、前端组件/格式器源码摘要绑定发布版，启动核源码、页面接口映射及显示因子，不符拒绝启动。仅策略字段允许 `call_api` 换成页面显示值、标单位并直接回答；其它金额须同记录/同列页面核对。单价复合单位（如元/天/KG）须 `unit_source` 组件及 SHA256，启动从同字段字面单位验，不默认元。附带策略仅为隔离合成实例取得非零同记录样本的 14 个开发候选，云默认不启用，须该部署同账号逐字段核验后显式安装。

未开用户态源码时，实现问题固定说明本部署不提供源码，不凭记忆猜；开启后的引用/拒答边界同通用合同。普通操作不要求源码。

`done` 前核对正文及交付项中的可追溯读数（芋道提供）：金额/数量/百分比须在本轮起始页面、工具结果或用户原话出现，统一千分位、尾零和正号，保留负号含义；字母数字混合单号/产品码须完整逐字，不归一大小写/前导零/分隔符，不认片段；日期、时间、纯数字 ID、电话、地址不抽取。无来源清单最多交回同一模型一次，可改用已读值、说明计算依据/无法核实，编号须原样。纠正后仍无来源、请求模型失败或预算不足时，交付项中的无来源值使该项及本轮未完成；仅正文解释中的无来源值保留 `done` 并在答复末尾明确列出。审计 `untraced_numbers` 记清单、是否交回及受影响项；`need_input/cannot` 不检查。

## 暂存表单与交接

### 字段、选项与新鲜度

只改审核暂存字段，交接前核对同表单/实时值并提示人工核对提交，从不点提交。批量每次最多 20 字段，超限整批拒绝不截断，长表单分批/滚到提交区，不能核对不报完成。续轮沿用同一有界会话用户给字段，当前明确收窄不从历史扩充，新会话不继承；单位装饰可在标签唯一时省略，枚举括号排版可按 actor 唯一原生选项解析，关系名仍精确匹配。部分已填后失败须指出停止字段/已执行步骤，不重发，草稿交用户。

实时 `readElementPageControl` 可给 `kind:form`、`mode:create|update`、`recordId`（新建 null），Runtime 从控件取模式/ID并纳入新鲜度，不信页面摘要同名文字。芋道以挂载表单模型和实际新增/编辑标题为准，嵌套明细从唯一主表单取状态；多主表单、未知模式、编号矛盾或中途改变均拒绝，逐步核同一实例。关闭编辑预填时仍可新建、开编辑供人工填写，不凭请求动词判模式。

选择在同一所属列表有界展开、精确标签查找，歧义/禁用拒绝；不存在时交回有界脱敏标签，不替名字。新增草稿明确类型的关系字段先试用户给的名称，再用本字段选项纠正，本地不足才范围读取。下拉后无唯一当前控制器序号则不收起，仍验草稿/表单未变。只有 Runtime 证实未选选项且草稿未变，加应用可选证明同表单/账号才可纠正；其它已发出但核验失败动作结束。

新增/编辑日期精度取挂载控件类型并计新鲜度；单日期保留原文，标准日期时间仅给日期时填当日 `00:00:00` 并验读回。自定义显示格式/范围/未知控件不靠占位字猜。

### 批次、草稿意图与完成

`goto(open=...)` 可合并审核表单入口。`fill_fields(then_highlight, answer)` 逐字段准入/核验，服务端回读用户给字段及此前未填字段，再按 Runtime 交接验值/高亮。可先以确切审核按钮 `add_lines` 新增 1–4 行，每行保持同表单/旧值；无标签明细按精确 ref/实例。ERP 销售订单/其它入库的产品自动单价须同账号精读产品核对，其它未填值保持。筛选批次 `then_click/answer` 仅真实查询回执经应用核验才能结束，缺字段/填失败不搜，屏幕外/替换/不完整字段继续观察。

当前明确“先填/只填/预填/不提交”，或编辑表单改值但未要求保存，服务端在 Skill 持久提案前拒绝并留草稿路径；“不要直接提交/别立即保存”不当肯定，明确改完保存则不过此门禁。同名记录查空时提醒仍可新增草稿。填写前按本轮点名字段核对内容；批量整批检查，并参照表单其它字段标签：未点名字段须本轮字面值；本轮无点名的指代可沿用此前用户字段，不能由助手上轮答案扩展。失败整批不填，要求缩字段/澄清。新请求明确改值/提交时另走已安装 Skill 与新审批，旧编辑表单不证明本轮只预填。

固定 v2026.09 处理器审核覆盖 ERP 供应商/仓库/产品查询、分页、暂存表单，以及销售/采购订单查询、分页、只读详情弹窗。明细加行可按受限结构或审核确名放行，均验危险按钮并证同表单只加一行；不含提交/状态变更/删除。

写关闭时不判断保存意图（“审核/改成”只描述数据），不做完整请求模型复核，未开放页面步骤在答复后列未执行。写开启而本轮无持久工具时，预填/办理完成（包括动作携答和 `finish(done)`）须对照完整原话、程序填值/高亮、真实表单/查询复核；只开列表/漏字段不算。只读可降级确切业务按钮交接，须明确未办理；最多一次纠正，不可用/仍分歧不报完成；纯查询/普通导航不增复核。模型语义复核会增调用，仍可能误判。

### 业务按钮高亮

无对应写操作时，slim 尝试先筛唯一记录，再高亮删除/审核/确认/启停供用户操作，危险按钮不点击。列表须当前 GET 仅一行、同名按钮唯一，可见 `name/no` 筛选出自用户原话且等于该 GET 同字段摘要；销售订单 `no` 仅 1–64 位字母/数字/连字符/下划线。其它筛选、未生效、多行或摘要不符均不足。详情须应用确认路由、actor 详情验 ID，且用户给 ID 或名称搜索证唯一；详情不可读/重名无 ID 不标。目标/控件不能证实时说明无法安全交接，高亮不表示办理完成。

系统用户状态开关交接须列表唯一、原表格/开关绑定、同账号重放实效筛选仍唯一同 ID，并详情核账号/昵称/状态；昵称唯一或用户给编号/账号，只标实际开关，不点击/报启停。

## 原生写入

三十项原生操作分二十四个业务 Skill 包：客户创建/资料、既有客户下联系人创建/资料、公海释放/领取/锁定/成交状态、线索维护、复合跟进、回款计划、ERP 供应商/仓库/客户/产品、系统部门/岗位/通知、商城品牌/分类、会员标签/分组、流程分类。消歧、层级、单位、实体区分共用应用资产并装配为受控按需 references，完成条件留正文。关系名/层级路径经 actor 读取绑定外键，ERP 价格元/重量 kg；当前字典约束提案，准备和派发复查；静态解释引已加载确切段落。

新建定义记录不分配用户、会员或权限，不部署/发起流程；系统通知仅建记录不推消息。公海/状态、回款计划及 OA 发布用专用合同展示/验连带效果；OA 用动态下属，不支持固定接收名单。原生接口未暴露的负责人时间/历史元数据不声称独立核验完成。芋道与 Contacts REST 实现同一效果合同，合同测试不证明模型准确率或速度。

跟进副效按主对象：客户/线索更新最近时间、下次时间、最近正文、已跟进标志；联系人不更新标志，商机不更新最近正文，合同只更新最近时间。同一应用定义供审批/投影/回读；必需字段在审批及派发前均可读，确认后副效不全仍不确定。

错误类别/代码脱敏记对账。已有确切目标 ID 的更新/状态变更可在错误后同 actor 回读证明完整效果，否则仍 `indeterminate`，一次没查到不改判失败。复合跟进可能报错前已插记录，没有可归属确认 ID 则不确定，绝不重试。

原生写卡仅对当前审核 CRM 联系人列表上的“新建联系人”确切提案提供“只填到表单，我自己提交”：字段仅姓名/手机/职位、当前 actor 负责人和唯一可见客户。服务端重核客户名与提案 ID，再打开新增/选客户/填字段/验实时表单，不派业务写。其它操作不提供此项。`stale_observation` 表示派发前拒绝，可重观后仅再试一次；已执行但核验不明的动作不重试。

## 审计与私有回合记录

普通读取审计只记已安装接口路径、参数名、页码/大小、发布选取字段、实读行数、声明总数及读全状态，不记筛选值/记录内容；可复核路线/范围，不能证明模型条件符合意图。

默认每回合写 `<state-dir>/runs/<会话>/turns/<序号>.json`，与审计同目录：提供方已接受且通过出口检查的请求消息（逐条去重）、工具名/答复、用户原话、起始路由、账号摘要、终态、耗时/答案；整份再查凭据形式，发现则只留终态/耗时。读取引用另存最多四份 `server_deliveries`：本轮引用、来源/计算投影、应用回执的实际来源引用（若有）、实际排版正文及完整交付状态。来源绑定被引用结果，不取最后读取/模型自填；终态可能随后变化，消费者须重绑最终答案/终态。

该记录含模型看到/服务端交付的业务值，不入普通审计、不回模型上下文。权限 0600；`--turn-trace-days` 默认 14 天，0 禁写，启动及之后每小时最多一次清过期文件。
