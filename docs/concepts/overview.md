# 系统概览

Web Operation Agent 是一个嵌入第一方业务 Web 应用的 AI 助手框架。用户在应用页面里用一句话描述目标；服务端负责理解、规划、调用知识与业务接口，页面内的 Runtime 负责观察当前页面、执行固定的通用动作并返回回执。

## 两层结构，一个逻辑 Agent

推理只发生在服务端。浏览器 Runtime 通过版本化协议与服务端隔离，不持有计划、业务知识、模型凭据或审批权。

```text
第一方页面
  assistant.js + 面板 + 固定浏览器工具
                    │ 已认证的观察／动作／决定
                    ▼
服务端
  会话策略 · 规划与模型 · 审批 · 审计 · 持久状态
                    │ 类型化应用端口
                    ▼
应用 Adapter
  身份 · 路由 · 读取 · 写入 · 核验 · 可选源码
```

服务端与浏览器之间：页面观察、动作结果、用户消息和审批决定经认证的 POST 上行；动作与进度经 SSE 下行。Runtime 只执行服务端下发、并通过当前观察、页面 epoch、截止时间和 capability 校验的命令。

**Runtime 不含**：任务历史、模型客户端、源码、Skill 目录、业务 evaluator、任意 JavaScript 执行。**Adapter 不含**：模型、规划、策略——它只提供应用事实、权限和可执行端口。

## 为什么这样切

- **凭据与知识不出浏览器**：模型凭据、源码索引、隐藏权限、业务计划都留在服务端。Runtime 被攻破不会泄露这些。
- **应用差异挡在 Adapter 后面**：核心包应用无关。应用行为只经 Adapter、Skill、类型化工具和应用自己的核验进入，核心不含任何应用的模型名、RPC 形状或意图枚举。
- **执行与成功分离**：`AgentTurnExecution` 只陈述执行事实（终态、步数、答复、结果摘要）。业务是否真的成功，由应用在同一 actor 下核验决定，不由模型自述、HTTP 2xx、页面提示或用户点过批准来断言。
- **写入默认拒绝**：核心配置默认关闭所有可能触发应用写入的浏览器动作，Adapter 显式开放自己审核过的子集。

## 信任边界

| 边界 | 假设与约束 |
| --- | --- |
| 用户输入、模型输出 | 不可信；严格 schema、长度与参数校验；模型只能经结构化工具调用行动 |
| 页面 DOM 与页面文本 | 不可信运行时数据；可改变计划，不能发出服务端指令或扩权 |
| Embedded Runtime | 只信任固定实现与当前活动 lease；无模型凭据、业务 token、源码、控制计划 |
| 会话通道 | 校验 capability、Origin、lease、schema、大小、截止时间与重放一致性 |
| Application Adapter | 受信任的集成代码；负责身份、参数规范化、接口范围与错误分类 |
| 审批与写入 | 受信任的确定性边界；批准绑定精确提案，不确定默认拒绝且不重试 |
| Evaluator | 独立最高信任读取端；Agent 与 Runtime 不得访问隐藏真值 |

所有跨浏览器边界的数据都检查凭据形态与会话交接参数；填写的值不进入动作描述或参数回显；审计在落盘前再次脱敏。原始 capability 只进入短期 bootstrap 与 Runtime，registry 只存哈希。

页面观察、接口结果、Skill 与源码证据在发给模型时都标记为**不可信应用数据**：模型可以用其中的事实，但不能据此扩大任务、获取授权、索取凭据或重定义工具。

## 状态语义

`AgentTurnExecution.status` 说的是循环如何结束，不是业务成功：

| 状态 | 含义 |
| --- | --- |
| `FINISHED` | Agent 声称完成，或返回了允许直接结束的只读答案；仍需应用核验 |
| `REFUSED` | 明确表示无法完成 |
| `CANCELLED` | 用户拒绝了精确写入提案 |
| `INDETERMINATE` | 写操作可能已发生且无法证明；禁止自动重试 |
| `FAILED` | 预算、provider、策略或其他运行错误导致结束 |

对 `INDETERMINATE`，用户可见答复固定说明结果不确定，不能被模型生成的乐观文本覆盖。

## 当前实现的边界

- 会话注册表、实时事件序列、消息队列和活动 lease 仍在单进程内存中；可选 SQLite 存储可在进程重启后恢复有界历史、消息去重墓碑与所有权，但会重新签发 capability 与 lease，绝不恢复页面事实、审批、凭据或执行权限。
- 没有跨实例调度与服务级高可用；进程崩溃会中断当前任务，中断的消息不自动重跑。
- 浏览器自动化不提供数据库事务或回滚。
- 嵌入模式假定第一方页面可信；面向第三方页面、需要更强隔离的执行端尚未实现。
- 真实数据的字段级分类、provider/区域策略与保留期由部署方提供；在此之前不应把含真实客户数据的页面接入。
